
📍 FacilityFinder: 공공 체육 시설 탐색 및 관리 플랫폼FacilityFinder는 서울시 공공 체육 시설 데이터를 기반으로 사용자 주변의 운동 장소를 찾고, QR 코드를 통한 시설 입실 관리 및 데이터 시각화를 지원하는 Flutter 기반 모바일 애플리케이션입니다.🚀 프로젝트 개요 및 기술 스택구분내용주요 목표공공 체육 시설 정보 제공, QR 기반 입실 시스템, 위치 기반 시설 지도 구현 및 이용 통계 제공.개발 언어Dart프레임워크Flutter상태 관리/아키텍처Provider, MVVM (Model-View-ViewModel)핵심 백엔드/DBFirebase (Authentication, Firestore)주요 외부 API서울시 공공체육시설 API, Google Maps API🛠️ 개발 환경 및 사용 도구IDE 및 환경: Android Studio, Flutter SDK, Git백엔드/DB: Firebase (Authentication, Firestore, Cloud Functions)위치/지도: Google Maps API핵심 패키지: GoRouter, Provider, fl_chart, mobile_scanner (QR)💻 프로젝트 기능 상세 및 구현 내용1. 인증 및 계정 관리 (담당: 김동영)Firebase Authentication: 이메일 및 비밀번호 기반의 회원가입/로그인 로직 구현 및 사용자 세션 관리.인증 흐름 최적화: main.dart와 router.dart를 연동하여 로그인 상태에 따른 초기 화면 전환(로그인 페이지 vs 홈 화면) 처리.2. 지도 및 위치 기반 서비스 (담당: 김동영)Google Maps API 연동: map 폴더 내의 핵심 로직으로, 사용자 현재 위치를 중심으로 주변 공공 시설을 마커로 표시.커스텀 마커 및 정보창: 시설의 종류나 상태에 따라 지도 마커를 다르게 렌더링하고, 클릭 시 상세 정보로 이동하는 인터페이스 구현.GCP 설정: Android/iOS 배포를 위한 SHA-1 지문 등록 및 API Key 보안 관리 수행.3. QR 코드 입실 관리 시스템 (담당: 김동영)QR 스캔 로직: qr 폴더 내 구현된 기능으로, 시설에 비치된 QR 코드를 스캔하여 사용자 출입을 인증.Firestore 연동: 스캔 완료 시 해당 시설의 이용 기록을 실시간으로 업데이트하여 이용 통계 데이터의 기반 마련.4. 라우팅 및 시스템 아키텍처 (담당: 김동영, 김태호)GoRouter 기반 설계: router.dart를 통해 복잡한 화면 이동 경로를 중앙 관리하고, 파라미터 전달 방식을 표준화.MVVM 패턴: image_6417df.png의 구조와 같이 기능별로 View와 Logic을 분리하여 협업 효율성 증대.5. 시설 정보 등록 및 조회 (담당: 김태호)Enroll/View: enroll/view 폴더 내 로직을 통해 새로운 시설 정보를 등록하거나 전체 리스트를 조회하는 기능 구현.공공 API 파싱: 서울시 공공서비스예약 API 데이터를 앱 내 데이터 모델로 변환하여 렌더링.6. 통계 및 데이터 시각화 (담당: 김태호)Stats Service: stats 폴더 내 구현된 기능으로, fl_chart 라이브러리를 활용하여 시설별 이용률 및 성별/시간대별 이용 통계 시각화.7. 사용자 홈 및 마이페이지 (담당: 김태호)Home UI: home 및 entry 폴더를 담당하여 앱의 메인 대시보드와 진입점 UI/UX 설계.Mypage: 사용자의 이용 기록, 즐겨찾는 시설, 개인 설정 등을 관리하는 프로필 화면 구현.
